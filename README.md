# StreamDiffusionUnity

Unity 6 (URP) project and package for interactive realtime generation with StreamDiffusion.

- **Use it as a package** in any Unity 6000.6 URP project: Package Manager > Add package from git URL:
  `https://github.com/LucaBiada/StreamDiffusionUnity.git?path=/Packages/com.lucabiada.streamdiffusion#v0.1.0`
- **Or open this folder as a Unity project** (6000.6.4f1). The sample scene is under
  `Assets/Samples/StreamDiffusionUnity/0.1.0/`.

Details, requirements and the first-run steps are in
[`Packages/com.lucabiada.streamdiffusion/README.md`](Packages/com.lucabiada.streamdiffusion/README.md).
